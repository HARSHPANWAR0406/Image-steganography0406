# Modular Image Steganography Lab

![Status](https://img.shields.io/badge/Phase-0%2F6%20Complete-blue) ![Language](https://img.shields.io/badge/Language-Python%203.x-informational) ![Domain](https://img.shields.io/badge/Domain-Information%20Hiding%20%26%20Steganalysis-orange)

A progressively-built steganography and steganalysis framework designed to encode covert data into digital images, analyze statistical anomalies, evaluate image degradation metrics, and detect concealed payloads.

> Aim: Hide quietly. Preserve fidelity. Extract accurately. Detect statistically. Expand capabilities iteratively.

```text

Stego Image Generation → Quality & Distortion Metrics → Statistical Steganalysis →
